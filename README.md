# mineria-datos-educacion-superior-chile
Proyecto de minería de datos aplicado a la matrícula de educación superior en Chile (2021-2025), utilizando técnicas de clasificación, regresión y segmentación para la identificación de perfiles estudiantiles y patrones institucionales.
 
Este repositorio contiene un notebook de análisis y procesamiento de datos desarrollado en Jupyter Notebook.
 
## Contenido
 
- `notebook.ipynb`: notebook principal con la carga, transformación, análisis y visualización de datos.
 
## Requisitos
 
- Python 3.x
- Jupyter Notebook
 
## Uso
 
1. Clonar el repositorio.
